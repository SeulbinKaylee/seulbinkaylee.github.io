## 파일 구조

```
.
├── index.html
└── assets/

    ├── main.js       # 테마 전환, 스크롤 애니메이션
```

## 로컬에서 보기

```bash
npx serve .
```

`main`에 push하면 GitHub Pages로 바로 배포돼요.

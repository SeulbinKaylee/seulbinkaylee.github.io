01 About

처음엔 새 언어와 프레임워크를 익히는 것 자체가 도전이었지만, 지금은 “어떻게 하면 이 문제를 더 단순하게 풀 수 있을까”를 고민하는 게 일의 대부분입니다. 대규모 데이터를 다루는 서비스, 오랫동안 여러 사람의 손을 거친 서비스, 보안 취약점 대응까지 — 기술적인 해결만큼 팀이 같은 방향을 보게 만드는 것이 중요하다는 걸 배웠습니다.

새로운 기술을 들일 땐 근거를 데이터로 설명하고, 팀을 설득하고, 끝까지 운영합니다. 화려한 아키텍처보다 새벽에 알람이 울리지 않는 시스템을 더 좋아합니다.

// principle 1

Measure first

느리다는 감 대신 실행 계획, 프로파일링, 지표로 병목을 찾습니다. 최적화는 그다음입니다.

// principle 2

Respect the legacy

오래된 코드는 오래 살아남은 코드입니다. 테스트로 감싸고, 작게 쪼개고, 안전하게 바꿉니다.

// principle 3

Secure by default

인증·인가, 입력 검증, 민감정보 처리는 기능이 아니라 기본값입니다. 나중은 없습니다.
